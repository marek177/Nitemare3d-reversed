## Behavior model
`1296(cellOffsetWORD,cellSelectorWORD)` is far cdecl and returns a far pointer in DX:AX on a hit. Pseudocode for ordinary non-wrapping lists:

```text
set DS to NE9
for i=0 while i < signed16(NE9.word[0]):
    record = NE9:word(9DD6h + 16h*i)
    if record.word[8] == cellOffset and record.word[A] == cellSelector:
        set DS=SS
        return record
set DS=SS
call 3118(0D90h)  # actual return/exception policy unresolved
```

The scan compares the actual far-pointer representation, not its normalized linear address. `1476` dereferences the returned far record and checks its WORD+0C. `84F4` tests AL from1476, rejecting with E3B0(WORD1,DWORD0) and AX0 when AL0. On success of both gates and with no other flag bits set, full original direction WORD is returned.

The decompiler's near/int-looking return type for1296 hides the explicit `MOV DX,ES` before RETF; use the native instructions for the far return contract. Similarly, the temporarily switched DS matters when locating the record array. Do not identify states0/4 as specific door states without producer/update evidence.

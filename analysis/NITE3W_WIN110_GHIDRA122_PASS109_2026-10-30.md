## Behavior model
If enabled, sample a6-byte local input record `(xWORD,yWORD,flagsWORD)`. Evaluate button events with000D precedence over001B. Compute32-bit modular elapsed; when>200 set timestamp=now then emit Y event followed by X event using signed thresholds. Finally update two button-state bytes. No axis event inside-7..7; timestamp still advances on due neutral input. Unknown high button bits do not change tested low-bit decisions.

# Nitemare3D Windows 1.10 — pass120: collision dispatcher and state predicate

## Finding
Original `1010:84F4` makes an ordered decision from two two-byte cells, using two byte-indexed flag tables. `1010:1476` accepts exactly state WORD0 or4 at a supplied far record+0C. Evidence uses preserved Ghidra12.2 native export and original EXE microexecution, not a new Ghidra run or live Win16/game execution.

## Behavior model
Inputs: `84F4(cell1.offset,cell1.selector,cell2.offset,cell2.selector,directionWORD)`, far cdecl. Cells can use different selectors; the fixture deliberately uses5000:7000 and6000:7100.

```text
w1 = table7E94[cell1[0]]; w2 = table7E94[cell2[0]]
if ((w1|w2)&04): E3B0(1,0); return0
for each cell and cached w in order:
    if w&08 and AL(1476(1296(cellFar)))==0:
        E3B0(1,0); return0
for each cell and cached w in order:
    if w&40: BFD8(lowByte=cell[0])
o1 = table7F94[cell1[1]]; o2 = table7F94[cell2[1]]
for each cell and cached o in order:
    if o&04: CF60(cellFar)
return0 if ((o1|o2)&02) else directionWORD
```

The BFD8 argument's high byte is not explicitly cleared by this caller; this pass validates the low byte only and does not assign a wider contract to BFD8. Two cells with the same identity are not deduplicated by the observed code. Snapshot timing is directly supported by the listing; mutation during child handlers was not dynamically exercised. Unused flag bits have no direct decision role in this routine.

## Verification
Run `python3 pass120/verify_collision_dispatch.py`: **200704 cases**:
- 65536 first-table flag pairs (every BYTE×BYTE), second-table flags zero, predicate stubAL1.
- 65536 second-table flag pairs, first-table flags zero.
- 4096 cross-products of relevant wall bits[04,08,40], object bits[02,04], and predicate return WORDs[0000,0100,0101,FFFF]. This distinguishes AL from fullAX.
- 65536 original1476 states, with nonzeroAH preserved.

The dispatcher runs original instructions;1296/1476/BFD8/CF60/E3B0 callsites are stubbed for controlled returns/events. Original1476 is separately executed. Checks cover exact event order/arguments, returnAX, far-cdecl stack and preservedBP/SI/DI for dispatcher. Direction rotates among0,1,FFFF,8000,1234. Both cells use controlled distinct byte IDs, with synthetic class-flag tables. No API, real map, game timing or collision handler side effect is claimed. Calls are intercepted before selector relocation is needed; no original code bytes are patched in this fixture.

## Implementation-ready findings
Preserve the early wall rejection, two sequential predicate gates, wall callbacks, then object callbacks, then object-blocking decision. Do not return early for second-table bit02 before invoking requested callbacks. Test the predicate's AL only. Preserve arbitrary allowed direction WORD rather than normalizing to1. These rules close the direct return-dispatch contract used by pass119; full collision parity still requires actual1296 and handler execution.

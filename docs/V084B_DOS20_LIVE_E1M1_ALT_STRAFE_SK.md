### What this proves

- Ordinary Left and Right **rotate** while leaving player coordinates unchanged, with the original heading changing in **6-unit steps**.
- The original game's ALT modifier changes Left/Right input into **lateral translation without heading rotation**, directly witnessed in one original E1M1 scene.
- Alt+Right produced three observed `(0,+11)` moves before position stopped changing even while the input remained held. **A collision is plausible but not confirmed at instruction-level.**
- Alt+Left produced mostly `(1,-11)` / `(2,-11)` movements and ended at Δ(+40,−329) with heading unchanged, consistent with a long strafe path and geometry restrictions.
- Releasing the arrow while keeping Alt, and then releasing all keys, stopped further coordinate/heading updates even though the original render counter continued advancing.

The experiment does **not** identify the first 8086 input-mask writer or the exact physics step scheduler. Host time is not an original game tick and RAM reads were asynchronous; intermediate steps may have been missed.

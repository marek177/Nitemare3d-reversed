# Nitemare 3D DOS 2.0 — runtime renderer/raycasting, 2026-10-19

## Výsledok
Vykonané sú reálne čiastkové runtime skúšky originálu v E1M1 a DEMO E1M11. Nie sú vykonané všetky testy celej oblasti a pixelová parita remaku nie je overená. Tento balík je referencia originálu a evidencia konkrétne pozorovaných javov.

Build: `all-nite3d.zip → nite3d/dos/nd-3-20/N3D.EXE`, Author Direct shareware V2.0, potvrdené úvodnou obrazovkou aj FILE_ID.DIZ. SHA-256 EXE: `a3fa02335e1d8bc531918f3bfaa66217aef65c81e562a2fdf1c749be652ca485`. MAP.1: `3eddb0ad3a29e93d63fa16e9b8cfbb434d3699a84bd5372ed2d6f4a1e89c42fc`.
Emulátor: priložený DOSBox-X Heavy Debug 2026.10.01, normálne CPU jadro, fixed 12000 cycles/ms, SDL surface, bez zvuku. Vstupy sú hostiteľské XTest udalosti; ich trvanie nie je počet herných tickov.

## Čo stále chýba k všetkým runtime testom
1. Kontrolované x/y/uhol vrátane presnej osi a rovnosti vzdialeností; trace writer→reader pre projekciu, clipping a textúrové vzorkovanie.
2. Každý typ dverí/panelu vrátane secret door a remote trigger vo všetkých fázach, z oboch strán, s predmetmi a nepriateľmi v zákryte.
3. Systematická matica hĺbky wall/sprite, sprite/sprite a rovnakých vzdialeností; dosiahnuteľné krajné veľkosti.
4. Úplné weapon/projectile/impact/death/boss vizuálne vetvy, všetky assety a epizódy. Tento vykonaný build je shareware, nie overená full v2.0.
5. Priradenie každej zmeny palety ku konkrétnemu kódu/stavu; scanline/raster timing v nástroji nie je úplne overený.
6. Identický herný stav originálu a remaku a byte/pixel diff ich framebufferov. Vstupný balík neobsahuje pripravený porovnávací build remaku ani synchronizačný kontrakt.
7. Deterministické opakovanie vstupov podľa herných tickov; hostiteľské časovanie XTest ho nenahrádza.
8. Overenie mapy po splnení gameplay podmienok a overenie všetkých nastavení zobrazenia.

Žiadne percento runtime/parity sa týmto reportom nevyhlasuje za 100 %. Skoršie označenie 100 % STATIC CORE je iná metrika a tento runtime ju necertifikuje.

## Reprodukcia a obsah
`evidence/` uchováva originálne .n3dt, PPM, .vram, .pal a metadáta. `analysis.json` je odvodený súpis. `actions*` sú záznamy hostiteľských akcií, NIE tick-presný replay. `test.conf` zaznamenáva emulačné nastavenia; absolútne cesty treba prispôsobiť. `tools/` obsahuje pôvodný dekodér, coverage a RGB/VGA diff z priloženého toolkitu. Príkazy a ich obmedzenia sú v pôvodnom README_SK toolkitu.

N3DTRACE VGA SNAP je okamžitý snapshot pri zastavení debuggerom, nie garantovaný koniec snímky. G udalosť je registrový snapshot, nie automatický dôkaz konkrétnej raycasting funkcie. Časové medzery medzi experimentmi a vyčerpanie limitu sú súčasťou protokolu.

## Dôvera
High pre identitu buildu, počty zachovaných udalostí, rozmery a hashové/pixelové porovnania uložených dát. Medium pre vizuálnu klasifikáciu konkrétnych scén. Unknown pre celkovú percentuálnu úplnosť a presnú 1:1 pixelovú/timing paritu.

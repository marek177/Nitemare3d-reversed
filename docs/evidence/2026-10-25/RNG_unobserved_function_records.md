## Shared call contract and register/FLAGS dependencies

`0FBA:01A0` performs FAR CALL `11EE:31F8`, then RETF. The core calls `11EE:3AD8` (stack-based 32-bit product), adds `0x00269EC3`, writes DS:24B8/24BA, copies DX to AX and executes **AND AH,7Fh** at 11EE:321C. Thus AX is 0..32767, DX retains the high state word, CX is clobbered (the multiply helper loads the low multiplier 43FDh); BX/BP are restored by the helper, SI/DI/DS/ES are untouched along this byte-visible path. FAR call/return and RETF 8 in the helper balance their own stack frames and arguments. This contract assumes valid DS, stack and unmodified executable bytes; IRQ/external effects remain outside it. Upper halves of EAX/ECX/EDX are not overwritten by these 16-bit operations.

FLAGS at wrapper return come from the **8-bit AH** mask, not from a 16-bit AX test: CF=OF=SF=0; ZF and PF reflect masked AH; AF is undefined; unrelated control flags are preserved by this path. In particular AX=1 may coexist with ZF=1. Callers here establish fresh arithmetic FLAGS before conditional use; carrying pre-call FLAGS through RNG is invalid. MOV, LES, CWD and CALL/RETF do not establish arithmetic predicates. CWD reads AX, writes DX only and preserves FLAGS; IDIV reads DX:AX and divisor, writes AX quotient and DX remainder, leaves arithmetic FLAGS undefined. Every following branch must be tied to a later defined producer, not IDIV.

## Indirect dependencies and remaining implicit-effect audit

1. **Confirmed:** five bounded CS tables supply the selector mappings above. This closes these local table choices for this source EXE, not callback registration, all incoming paths, mutable runtime targets or cross-version behavior. JSON direct inbound edges are candidate-context evidence only. Follow DS:3D22 class records, their +34/+36 callback fields around 04C7:0E4D/0E8E, and descriptor +06 producers before attributing actor names.
2. **Confirmed:** CWD/IDIV and one-operand IMUL/MUL are live dependencies. The coordinate gate's two IMUL operations write DX:AX and define CF/OF while other arithmetic flags are undefined; the next IMUL consumes only AX and CX. OR at 1692, not IDIV, supplies JLE's predicate. Do not use mathematical unlimited-width multiplication or a stale DX dividend.
3. **Confirmed:** 11EE:3ADE–3AE6 uses OR CX,AX then MOV CX,[BP+0A] then JNE. MOV preserves the OR predicate; a flag writer attached to MOV would change multiply dispatch. Byte partial writes (AH masks, AL &7, zeroing BH/CH) require lane-aware dependencies. LES/LDS change ES/DS and register values; BP locals default to SS, SI/DI/BX operands default to DS unless overridden. Segment aliases are unresolved outside the byte-local contract.
4. **Audit still required:** REP STOS/MOVS/LODS/SCAS count, DF, SI/DI, implicit memory widths and segment defaults; LOOP/JCXZ counter width without arithmetic flag writes; PUSH/POP/ENTER/LEAVE, FAR CALL/RETF and interrupt stack layouts; LAHF/SAHF/PUSHF/POPF/IRET, ADC/SBB carry chains, shifts/rotates with CL/count-zero and undefined flags, IN/OUT implicit accumulator/port, XLAT, string I/O, BOUND and divide faults. Capstone's register access lists alone are not proof of complete byte-lane, memory or conditional effects.
5. No new general decoder defect beyond the existing 98/99 correction is asserted. This change preserves that correction with CPU regression tests and adds a byte-pinned follow-up decoder path using iced. It does not rewrite CFG edges or boundaries, patch game binaries or label unaudited effects as corrected.

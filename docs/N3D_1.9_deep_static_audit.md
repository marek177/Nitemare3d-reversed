# Nitemare-3D DOS V1.9 – hlboký static audit functions

Reference file: `n3d-d19.exe`  
MD5: `b395d92440d153535b73464dc60058ec`  
MZ header: `0x1C00` bytes  
Relocations: **1669**  
Priame far-call instructions v hernom code: **1413**  
Unikátne priame far-call targety: **367**

## Architektúra

- 16-bit DOS MZ, segment memory model, rozsiahle `CALL FAR` / `RETF`.
- Code uses also 32-bit operand-size prefixy (`66h`) v 16-bit mode.
- Runtime identify: `MS Run-Time Library - Copyright (c) 1992, Microsoft Corp`.
- String segment V1.9 is during `276D:xxxx`.
- Very time use data segment v game code: `21F9h`.

## Najdôležitejšie structures

### OBJECT runtime – 28 bytes (`0x1C`)
Initialize block okolo linear `0x0B7BC` creates OBJECT records with krokom `0x1C`.

Confirmed arrays:
- `+0x00` byte – type/map object id
- `+0x01` byte – derived variant/subtype
- `+0x02` byte – initialize on 0
- `+0x03` byte – status/frame (uses sa as index to sekvenčných tabuliek)
- `+0x04` byte – sekvenčný/class index
- `+0x05` byte – flags
- `+0x06` byte – runtime object class
- `+0x07` byte – GUARD index during objektoch with guard flagom
- `+0x08..+0x0B` dword – during spawne zero
- `+0x0C:+0x0E` far pointer back on map prvok / map cell
- `+0x10` word – world X, stred cells (`0x20 + 0x40*n`)
- `+0x12` word – world Y, stred cells (`0x20 + 0x40*n`)
- `+0x1A` byte – derived runtime/render/sequence parameter

Limit OBJECT: **350 (`0x15E`)** – confirmed through `MAXOBJ exceeded (%d)`.

### GUARD runtime – 26 bytes (`0x1A`)
Array starts on `21F9:264E`, stride `0x1A`, maximum **100**.

Math check:
`264E + 100 * 1A = 3076`, what exactly ends on start nasledujúceho door array.

Confirmed arrays:
- `+0x08` word – index to OBJECT array
- `+0x0B` byte – `state`
- `+0x0C` byte – `next_state`
- `+0x0D` byte – `o_id`

To is directly confirmed error format:
`Problem with guard: state=%d, next_state=%d, o_id=0x%x`.

### DOOR array – 18 bytes (`0x12`)
Base `21F9:3076`, stride `0x12`, maximum **64**.

Range:
`3076 + 64 * 12h = 34F6`.

Lookup function on start code compares:
- `+0x04`
- `+0x06`

and during nenájdení calls `Door not in map`.

### PANEL array – 14 bytes (`0x0E`)
Base `21F9:34F6`, stride `0x0E`, maximum **32**.

Range:
`34F6 + 32 * 0Eh = 36B6`.

Initialization is naviazaná on `MAXPANELS exceeded (%d)`.

### PUSH array – 6 bytes
Base `21F9:36B6`, stride **6**, maximum **12**.

Confirmed:
- `+0x00` word – OBJECT index
- `+0x04` byte – during initialize 0
- lookup subsequently through OBJECT `index * 0x1C` checks world coordinate `+0x12/+0x14` v corresponding usage object-layout kontexte.

Error: `Push not in map`.  
Limit: `MAXPUSHES exceeded (%d)` with hodnotou **12**.

## Spawn / map scan

Function okolo `0x0B7BC` skenuje 64×64 mapu:
- X/Y step `0x40`
- initial stred cells `0x20`
- OBJECT record `0x1C`
- during flags bit `0x08` sa zakladá GUARD
- GUARD limit 100
- special runtime classes `0x2F`, `0x30`, `0x36` set bit mask v global.

After terminate sa writes count OBJECT to global countu and verifies sa valid štartovacieho bodu (`Invalid start point(s)`).

## GUARD lookup / diagnostika

Block `0x06180–0x06257`:
- iterates guard array from `21F9:264E`
- stride `0x1A`
- guard `+0x08` -> OBJECT index
- OBJECT index sa multiplies `0x1C`
- coordinate sa check proti object field
- during chybe vypisuje exactly `state`, `next_state`, `o_id`
- if sa guard nenájde: `Guard not in map`.

## Exploding-wall / special object handler

Function from `0x07F8C`:
- reads object bytes `+0`, `+1`
- mapuje their through class/flags tables
- testuje flags `0x40`, `0x04`, `0x10`
- searches object class `0x29`, fallback `0x2D`
- during failure: `Exploding wall not in map`
- subsequently prepisuje fields including `+0x03`, `+0x04`, `+0x06`.

## Object lookup / special-state handler

Function from `0x09278`:
- uses centrálny object lookup (`AE7:069C`)
- during NULL: `Object not in map`
- branchuje according to object `+0x03`
- contains zvláštnu branch for value/type `0x26`.

## Weapon jam

Linear `0x0F994` is very small wrapper:
- push DS
- push string offset `0x2008`
- calls local text/UI routine `0x0D9A4`
- string: `Your weapon appears to be jammed!`

To mean, that itself logic určujúca jam is inde; `0xF994` is only prezentačná function.

## VGA/render – important korekcia stride 0x50

Code `0x019C6–0x01F99` programuje VGA registers (`3C4h`, `3C5h`, `3CEh`, `3DAh`) and uses step `0x50`.

`0x50 = 80` bytes is tu **scanline stride planárnej VGA 320px screens**, nie OBJECT stride.

For OBJECT runtime is staticky confirmed stride **`0x1C` (28 B)**.

# Other Nitemare 3-D RE results

This area holds **non-WORX source**, self-contained research snapshots,
verifiers, tests, evidence manifests, and findings that do not belong to
`linker/` or `worx/`. The project’s historical gameplay docs and C++17
remake in `docs/` and `src/` are intentionally left untouched.

- [`worx/`](worx/README.md): WORX 2.1 discovery reports, original-byte static
  evidence, verification tools and tests; **all WORX source lives only under
  `../worx/`**.
- [`n3d/v057/`](n3d/v057/README_SK.md): separate v0.57 geometry, guard and
  damage cross-build static closure package. A research snapshot, *not* a
  statement that the GitHub game engine is now at 100% parity.
- [`n3d/VERSIONS_20261016.md`](n3d/VERSIONS_20261016.md): evidence-based
  original DOS/Win16 version census (11 detected version labels).

Distingish machine-byte witnesses from candidate algorithms and runtime
unverified behavior. Never distribute proprietary original `.EXE`, `.LIB`,
asset archives or compiler binaries in these folders.

# Original game data

Place the original Windows Nitemare 3D files here. The runtime uses the original
`MAP.*`, `IMG.*`, `SND.DAT`, `UIF.DAT`, `GAME.PAL`, `DEMO.*`, `ENDING.FLI`, and
related definition files directly.

`WING.DLL` and `DISPDIB.DLL` are **not** runtime dependencies of the reconstructed
build; SDL3 replaces their display/window path. Copies may be retained only as
reverse-engineering references.

The original game data is intentionally ignored by git. Do not publish proprietary
game assets unless you have permission to distribute them.

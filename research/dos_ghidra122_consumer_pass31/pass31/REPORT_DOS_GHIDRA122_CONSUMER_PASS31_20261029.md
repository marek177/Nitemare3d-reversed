## Behavior model
Analytical signature (names describe tested behavior): `ScaleColumn(sourceOffset, sourceSegment, textureColumn, x, y, translateFlag, xLimit)`; seven 16-bit arguments on a far-call stack. Returns number of columns selected for grouping.

At V1.9 entry 1156:04ce, source column base is `(sourceOffset + (textureColumn << 6)) & 0xffff`. i is the signed/wrapped result `2*(y-center)+1`. Reciprocal table supplies `floor(0x400000/i)` as a 16.16 sampling increment for the positive tested i.

If y>=viewportBottom: destination begins at viewportTop, count=viewportHeight, phase is the table value from pass 30. Otherwise destination begins at y-i, count=i+1, phase=0. For each row, sample source column base + integer phase (16-bit source wrap), optionally apply translation LUT, write primary-page memory at `(startY&255)*80+(x>>2)+row*80` modulo 65536, then advance phase by reciprocal. The original split words/carry implement this accumulator.

Grouping for the tested nonnegative x: when i>64 and signed x<=signed xLimit, the routine selects up to two columns on unclipped paths or four on clipped paths, stopping at the next four-pixel plane boundary. Otherwise it returns one. VGA mask ports are emitted by original code but their hardware effects are not modeled here.

## Verification
`/usr/bin/python3 scripts/verify_scaled_column.py` with Unicorn 2.x: six distinct images × widths160/304/320 × seven y offsets × x0/3/4 × translation0/1 × grouping enabled/disabled =1,512. Each case checks all video-memory write addresses/values, returned AX, far return, SP and restored DS. Source bytes and LUT are synthetic; reciprocal and clipping tables are generated by original code. i is positive and <=401 here; no claim for index zero, negative or out-of-table indices. No framebuffer/DAC parity claim.

Per-build entry bytes, page global, LUT address and SHA-256 are in consumer.json. At V1.9 primary page global DS012e, LUT DSd20a. Preserved Ghidra12.2 instruction exports and reconstructed input EXEs are included; no project database edits.

## Implementation-ready findings
The table is a split 16.16 phase representation with only the low eight bits of its integer part used by this consumer. Preserve the source stride64, integer/fraction carry, signed clipping branch, primary page, optional byte translation and group return. The table's byte at index i and word at index i-1 form the phase; index zero is not generated. Do not interpret it as a general 24-bit color table.

# Repository notice

This repository contains a clean-room/reverse-engineering reconstruction scaffold and technical notes for Nitemare 3-D.

The original game executable, IDA databases, videos, DLLs, maps, graphics, sounds, palettes and other proprietary game assets are **not distributed in this public repository**. Users must provide their own legitimately obtained game files locally under `data/original/` when using the inspection/import tools.

Reverse-engineering notes distinguish direct executable/data evidence from behavior inferred from walkthroughs, official documentation, or incomplete third-party reimplementations.
